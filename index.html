Production hygiene for agentic systems
Prompt caching · HMAC · secret scope · no PII to untrusted models
Standard
  • Prompt caching preserved by byte-stable system prompts and no mid-conversation tool mutation.
  • HMAC-SHA256 on every webhook; 60-second timestamp window; per-alert idempotency keys.
  • All credentials in `~/.hermes/.env` with mode 0600. No PII sent to models without explicit user consent.
  • Relevance for SAP delivery: the same operational patterns (deterministic tool schemas, secret scoping, replay protection, no-PII gating) translate directly to enterprise RISE with SAP + BTP AI Core deployments where prompt caching and per-tenant secret isolation are production requirements, not nice-to-haves.
